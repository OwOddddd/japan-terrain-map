# 日本地形地圖

勾選日本中學地理教材常見的地形（山脈・山地、火山、平野、台地・高原、盆地、河川、湖、半島、岬、湾・灘、海峽、海流、島、海溝、構造線、代表地形，共 17 類 440 筆），在附縣界的地圖上顯示範圍與地名。

- 地名以日文漢字顯示，上方附振假名，點名稱可聽日語讀音
- 可切換「主要／次要」等級，只顯示並操作該等級的地形
- 可切換日文／中文介面與地名
- 「起伏図」開關：國土地理院標高圖磚合成的色別標高＋陰影圖墊在地形下方，可用滑桿調整地形範圍的不透明度
- 搜尋框：輸入地名、讀音或中文名的一部分，跳到該地形並加框提示
- 勾選單一地形或縣時，地圖自動縮放到該處
- 「白地図を保存」：輸出只有範圍與編號的白地圖與解答。可選 A4 直式／橫式／畫面範圍，以及三種方式：A＝PDF 兩頁（正面地圖、背面解答）、B＝兩張 PNG、C＝一張上下（橫式為左右）合併
- 「テスト」：地名變成空格，點空格選填地名，答完按「答え合わせ」以百分制計分，可輸出結果圖片
- 「リンクを共有」：把目前的勾選與設定編進網址分享（GitHub Pages 版）。依每個地形的永久編號（`terrain.js` 的 `i`）編碼，日後增刪地形不影響舊連結；新增地形請給新號，刪除的號碼不要重用
- 寬螢幕為左側欄＋全高地圖，側欄可收合
- 點選 47 都道府縣，會勾選所有「有一部分在該縣內」的地形（以精緻版範圍判定，由 `tools/prefs.mjs` 產生 `src/data/prefs.json`）
- 範圍可切換「簡易」（手繪概略範圍）與「精緻」（依官方地形分類、相鄰範圍互相嵌合不重疊）
- 勾選內容可存成群組（存在瀏覽器中）
- 可輸出成 PNG 圖片（只含地圖、地名、縣界，不含操作介面）
- 手機版：地形選單收在底部抽屜，重疊的地名會先隱藏，放大後顯示

## 資料來源與準確度

| 內容 | 來源 |
|---|---|
| 縣界、海岸線 | 地球地圖日本（國土地理院），經 [dataofjapan/land](https://github.com/dataofjapan/land) 轉換為 TopoJSON |
| 火山、山、岬、島、半島、湾・灘、海峽等 207 筆的位置 | 國土地理院「[地名集日本](https://www.gsi.go.jp/kihonjohochousa/gazetteer.html)」（經 [sorami/gazetter-of-japan](https://github.com/sorami/gazetter-of-japan) 轉為 CSV）的代表點 |
| 46 條河川的河道 | 國土交通省「國土數值情報（河川）」平成18～21年，取各河川的同一河川コード全部流路後簡化 |
| 26 個湖泊的湖岸線 | 國土交通省「國土數值情報（湖沼）」平成17年，簡化後使用 |
| 起伏圖 | 國土地理院「地理院タイル（標高タイル）」z8，依標高上色並加陰影後縮放為單張圖片（`tools/relief.py`） |
| 精緻版的平野、盆地、台地・高原、山脈・山地範圍（117 處） | 國土交通省「國土數值情報（土地分類メッシュ）」昭和54年，1 km 網格。平野與盆地：低地＋台地格子從各自中心同時向外擴張、每格只歸一處；台地・高原：台地・火山麓地格子（可落在平野內）；山脈・山地：其餘山地・丘陵格子分給最近的山脈脊線。相鄰範圍共用同一條邊界後再簡化、平滑 |
| 其他地形的位置與範圍 | 依一般地理知識手動估算的概略位置 |
| 地形清單與主要／次要分級（原清單的優先／擴充） | 使用者整理的教材清單 |
| 精緻範圍中的三次盆地、日田盆地、牧ノ原、磐田原台地、蒜山高原、四国カルスト、平尾台 | 官方格子不到手繪範圍 4 成（小盆地、高原被周圍山地分走），改用手繪範圍對齊 1 km 格子，屬概略範圍 |

國土數值情報的資料經本站加工（篩選、簡化、平滑），並非國土交通省製作的成果；其中河川資料的使用條件為非商用。

**本地圖為學習用示意圖。** 平野、盆地、山地沒有官方公布的邊界，精緻版範圍是依官方地形分類由本站判定的；簡易版為手繪概略範圍；表中未列出官方來源的地形為概略值。網頁上點地名時的提示框會標出每個地形位置或範圍的來源。需要精確位置或邊界時，請參考[地理院地圖](https://maps.gsi.go.jp/)或教科書地圖帳。

## 建置

`index.html` 是由 `build.js` 產生的單一檔案：

```bash
node build.js
```

- `src/template.html`：頁面與程式
- `src/terrain.js`：地形資料（座標為 [經度, 緯度]）
- `src/data/japan.topojson`：縣界資料
- `src/data/rivers.json`、`lakes.json`、`precise.topojson`：由 `tools/` 內的腳本從官方資料產生（原始資料需另外從國土數值情報下載）
