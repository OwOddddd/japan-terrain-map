# 日本地形地圖　開發紀錄

依時間記錄每一輪的需求、討論後採用的方案、原因與已知限制。每次改版都更新本檔，commit 編號可在
https://github.com/OwOddddd/japan-terrain-map/commits/main 查看或還原。

- 公開網址：https://owoddddd.github.io/japan-terrain-map/
- Claude 版（只有擁有者可開）：https://claude.ai/artifact/Fn9fA8NTa5oxiNeg1oRXEE
- 原始碼：`src/template.html`（頁面與程式）、`src/terrain.js`（地形清單）、`src/data/`（加工後資料）、`tools/`（資料處理腳本）、`build.js`（產生 `index.html` 與 Claude 版 `japan-terrain.html`）

## 目前的整體設計（給接手者）

| 項目 | 做法 |
|---|---|
| 地形清單 | 依使用者提供的「日本地形清單_增修版.xlsx」，17 類 543 筆，分「主要／次要1／次要2」（原清單的優先／擴充＋補充清單）。每筆有永久編號 `i`（分享連結用，新增取新號、刪除不重用） |
| 縣界、海岸線 | 地球地圖日本（國土地理院），經 dataofjapan/land 轉 TopoJSON |
| 點位 | 207 筆以國土地理院「地名集日本」代表點校正（`tools/calib_points.js`）；小笠原諸島、沖縄島、尖閣諸島因官方點是群島中心而保留原值 |
| 河川 | 國土數值情報（河川）W05，依河川名＋手繪位置找出河川コード，取同一コード的全部流路（`tools/rivers.py`）。四万十川在資料中名為「渡川」。已移除零長度碎段（iOS Safari 會畫成大圓點） |
| 湖泊 | 國土數值情報（湖沼）W09（`tools/lakes.py`） |
| 精緻範圍 | 國土數值情報「土地分類メッシュ」G05（1 km，昭和54年）。平野＋盆地：低地・台地格子從各中心同時擴張；台地：台地・火山麓地格子（可套疊在平野內）；山脈：其餘山地・丘陵格子分給最近脊線，端點外只容許 hw/2+3 km、只留有格子落在脊線帶內的連通塊。TopoJSON 共用邊界後簡化平滑（`tools/precise.js`） |
| 精緻範圍補強 | 結果不到手繪範圍陸地格子 4 成者改用手繪範圍對齊格子並標為概略：三次盆地、日田盆地、牧ノ原、磐田原台地、蒜山高原、四国カルスト、平尾台。シラス台地刻意不補強 |
| 都道府縣對應 | `tools/prefs.mjs`：面以邊界頂點＋0.03°格點、線以內插點判定；點狀地形含山 2 km、岬・島 8 km、湾・灘 20 km 內的縣；海洋類不屬於任何縣；沖ノ鳥島手動歸東京都 |
| 起伏圖 | 國土地理院標高タイル z8，上色＋陰影後縮 0.6 倍、128 色 PNG 約 260 KB 內嵌（`tools/relief.py`） |
| 地名位置 | polylabel 錨點；地名約 8 成在範圍內就放範圍上，否則在 8 方向 3 距離找空位並畫引線（上限約 26px）；優先畫面內，無空位時隱藏（放大再顯示） |
| 分享連結 | `#s2.` 依永久編號編碼；舊 `#s1.` 依當時清單順序（＝編號−1）解碼 |

## 每一輪的需求與決定

### 1. 初版（commit 4c5b96c）
- 需求：勾選地形顯示範圍與名稱（漢字＋振假名、可關名稱）、多類同時勾選、群組儲存、預設縣界、點名稱發音、輸出圖片（不含操作介面）。
- 做法：d3 + TopoJSON 單一 HTML；手繪座標；Web Speech API；SVG 轉 PNG。

### 2. 清單擴充與分級
- 依使用者 Excel 新增 240 筆，刪除赤石岳、大台ヶ原山改名大台ヶ原；加入優先／擴充篩選（後改名主要／次要）。

### 3. 可信度說明
- 向使用者說明：縣界為官方資料，其餘當時為手繪概略；估計點位誤差數 km、範圍面積誤差 ±30〜70%。

### 4. 發佈到 GitHub Pages（742e432 前）
- 公開 repo OwOddddd/japan-terrain-map；手機版改底部抽屜；重疊地名自動隱藏。
- 修正：手機抽屜被壓縮無法捲動、移除「本土」按鈕。

### 5. 箭頭、地名位置、日中切換（28b5874）
- 海流箭頭改依線條末端實際方向；小比例尺時範圍類地名放在旁邊；日文／中文切換（預設日文）；統一「飛驒」。

### 6. 改用官方資料（daa0489）
- 使用者選擇：點位校正＋官方河道＋湖岸線＋三處平野試作。

### 7. 精緻版（32e19e1、6800606）
- 使用者要求精緻版相鄰範圍剛好嵌合、可與簡易版切換、手機滑動順暢。
- 手機閃動原因：CSS transform 加在手勢綁定的元素上造成座標回饋；改綁不動的外框。

### 8. 地名辨識（bef8e58）
- 錨點放在自己範圍內、放不下則引線指回；精緻版同類相鄰分 4 種深淺。

### 9. 都道府縣選擇（53e081a）、選取縣界實線（6c79c45）
- 以精緻範圍判定涉及的縣；選取的縣界為實線、在地形之上地名之下。

### 10. 大改版（6554e2e）— 使用者選擇 1A 2A 3A（另附解答圖）4B
- 電腦版左側欄（≥900px，可收合）；起伏圖；搜尋框（共通字不列全部、選中跳類別加框不自動勾）；勾選單一地形或縣自動縮放（一次勾多個不縮放）；分享連結；白地圖＋解答圖；測驗模式（百分制、錯誤標紅＋正解藍字、按兩次退出）。
- 資料修正：シラス台地、生駒山地（止於大和川）、奥羽山脈（不含下北）、簡易版關東平野、中文漏轉內戶萬豫。

### 11. 小範圍補強等（bb4703f）— 使用者選擇 1A 2A 3A，2 改為三種列印方式都可選
- 小範圍補強 7 處；永久編號分享連結；預設勾選（手機 8 條山脈、電腦 20 個代表）；引線上限與畫面內優先；起伏圖改獨立開關＋不透明度滑桿；白地圖 A4 直式／橫式／畫面 × A（PDF 兩頁）／B（兩張 PNG）／C（一張合併），附說明與示意圖。

### 12. 列印配色、作答欄、起伏圖可讀性（6f6de99）— 使用者選擇 1A 2A 3A 4A
- 1A：列印配色「印刷向け」只在白地圖輸出對話框出現，不影響畫面；白海、淡灰陸地、外框＋稀疏的黑白花紋（平野細點、台地斜線、盆地交叉線、山地∧），附圖例。
- 2A：新增作答欄頁。頁序：A＝PDF 3 頁（1 地圖、2 解答＝地圖背面、3 作答欄獨立一張），作答時地圖與作答欄並排不用翻面；B＝3 張 PNG；C＝一張上地圖下作答欄＋解答另一張。
- 3A：「彩色起伏圖」「灰階起伏圖」兩個勾選框互斥；地形範圍外框加粗。
- 4A：建立本紀錄。
- 實作細節：列印配色時海流改黑色（寒流虛線）、河川深灰、火山黑三角／山白三角、湖泊橫線、大地溝帶點狀；地形不透明度在列印配色時固定 100%；灰階起伏圖用 SVG 濾鏡去色並提亮。

### 13. 灰階起伏圖對比（a97acf5）
- 問題：灰階起伏圖太淡、高低對比不足。原因是彩色色階的亮度不隨標高單調變化（約 300 m 最亮、2000 m 最暗、3000 m 又變亮），去色後只能整體提亮，無法單靠調對比修正。
- 做法：`tools/relief.py` 另外產生依標高由淺（0 m）到深（3000 m）的灰階圖 `relief_gray.png`（48 階，約 170 KB），灰階模式改用此圖與對應圖例；移除原本的去色濾鏡。頁面增加約 230 KB。
- 使用者詢問：飛驒山脈、三国山脈、関東山地之間的高地沒有被範圍涵蓋。原因是清單中沒有這一帶的山地（筑摩山地、上信越高原一帶等），不是範圍標示錯誤；八ヶ岳、浅間山在清單中是點狀地形。

### 14. 補充 99 筆地形、次要拆成兩級（39f557a）
- 來源：使用者的「地形補充清單.xlsx」（89 筆＋7 處既有範圍偏窄）與本站列的補充名單交叉對照。使用者決定：屬於大範圍一部分的地形「疊加」，小的畫在大的上面；主次要依兩份清單，不一致時重新判斷。
- 分級原則：大面積類別（山地）主要數量少於分散的平野；次要多的類別拆成次要1／次要2，數量少的類別只用次要1。結果：山脈 主要23／次要1 25／次要2 19、火山 22/28/9、平野 24/21/13、盆地 20/16/8，山、台地等不拆。
- 分級不一致的重新判斷：筑摩山地→次要1（多數地圖帳未標）、六甲・金剛→次要1（與生駒山地同級，控制山地主要數量）、岡崎平野→主要（矢作川、工業地帶常考）、男体山→主要（中禪寺湖成因）、月山→次要1。既有的夕張山地、讃岐山脈、吉備高原改為次要1，使山地主要（23）少於平野主要（24）。
- 本站清單另外加入（使用者清單沒有）：金沢平野、佐賀平野、直方平野、肝属平野、十日町盆地、六日町盆地、大野盆地、鷹巣盆地、飯山盆地、常陸台地。上信越高原以使用者的志賀高原・菅平高原取代；笠置山地、石鎚山脈、渡島山地、石狩低地帯、石巻平野因與既有範圍幾乎重疊而不加。
- 疊加（`sub`）：九十九里平野・相模平野⊂関東平野、大崎平野⊂仙台平野、佐賀平野⊂筑紫平野、金沢平野⊂加賀平野、勇払平野⊂石狩平野、祖母傾山地⊂九州山地、西中国山地⊂中国山地。精緻版另外計算、畫在大範圍上方並用不同深淺。
- 新增平野・盆地・台地的簡易範圍由土地分類格子描出外形後簡化（`tools/gen_areas.js`、`tools/areas_spec.json`）；格子太少的高原（志賀、菅平、美ヶ原、大和、世羅）與秩父盆地用手繪範圍補強。新增山地依脊線分配格子，與相鄰山地仍嵌合；伊那山地、身延山地脊線往西／東修正，避免赤石山脈縮太多（3352→2304 格）。
- 既有範圍偏窄修正：越後山脈（北延到御神楽岳）、石狩山地（加寬、東大雪）、木曽山脈（南延到恵那山）、飛驒高地（北延到白木峰）、天塩・北見山地（加寬補上川北部）、四国山地（西南延伸）、紀伊山地（南延）。
- 分享連結：flags2 第 7 位元記錄次要2 是否與次要1 不同，舊連結的次要2 跟著次要1。順帶修正灰階起伏圖的連結會把不透明度讀成 100% 的問題。
- 中文名稱新增轉換字：恵惠、釈釋、摂攝、属屬、体體、氷冰、条條、砺礪、払拂、荘莊；ニセコアンヌプリ＝二世古安努普利、サロベツ原野＝薩羅別原野。

### 15. 起伏圖上未涵蓋的高地（3fb776c）— 使用者選擇 A＋B，C（大型火山加範圍）不做
- 分析方法：把土地分類格子中「大・中起伏的山地與火山地」但沒被任何範圍涵蓋的格子依連通塊排序。原因分四種：脊線偏移或寬度・端點限制（演算法）、清單沒有的山地、火山只以點表示、屬台地・高原類。
- A 修正脊線：日高山脈改沿實際主稜線（幌尻岳一帶）並加寬到 30 km（3554→5666 格）；朝日山地往新潟側加寬；出羽山地南延到月山；赤石山脈南延；飛驒山脈北延到親不知；紀伊山地往東北延伸到伊勢南部；両白山地南延到越美山地東側。
- B 新增（次要2）：渡島山地、越美山地（套疊在両白山地，辭典定義為両白山地的一部分）、関田山脈、津江山地。積丹半島的山地查無通用名稱，不加。
- 仍未涵蓋（刻意不處理）：浅間山・四阿山・草津白根山、ニセコ・支笏周邊、天城山、屋久島等火山山體（以火山點表示），以及積丹半島。

### 16. 白地圖題目可讀性（4eff4ed）— 使用者選擇 1A 2A 3A
- 問題：題目多時圈號重疊；範圍小時花紋看不出類別；勾選分布全國時只能縮成全國，小範圍看不清。
- 1A：白地圖的圈號在原位置之外，再往外圍 6 圈 × 16 方向（最遠約 80px）由近到遠找不重疊的空位並畫引線；點狀地形的符號也列為不可遮蓋；超過 40 題、80 題時圈號各縮小一級。只影響白地圖，平常畫面不變。
- 2A：圈號外形依類別區分（平野○、盆地□、台地・高原⬡、山脈・山地⬠，其他○），圖例改為「外形＋花紋（或顏色）＋類別名」並加大；作答欄與解答依類別分段加小標題，放不下時自動換頁。
- 3A：輸出視窗新增「範圍：依地方分頁／全國一頁」（預設依地方分頁）。地方＝北海道、東北、關東・中部、近畿・中國・四國、九州・沖繩，以都道府縣對應判定（跨地方取縣數多者，不屬任何縣的取最近地方）。題號全部接續；A＝各地方地圖與解答正反面、作答欄在最後；B＝各地方地圖、作答欄、各地方解答；C＝各地方地圖＋作答欄、該地方解答。地形很少時地圖範圍至少約 3°，保留周圍縣界作參考。

### 17. 外部建議回應（f4af940）— 使用者選擇 2A＋2B、5、6、7、8（VOICEVOX 日語）
- 建議 1、3、4 暫不更動。
- 2A：測驗題目框沿用白地圖的找空位＋引線，並避開點狀符號。實際查證：開始測驗時程式不改變縮放，重疊是題目框找空位範圍太小造成的。
- 2B：題目分布在多個地方時，測驗列出現地方分段按鈕（顯示已作答數／題數，評分後顯示答對數）；切換時縮放到該地方（避開測驗列高度），只顯示該地方的題目框，選項也只列該地方。
- 5：側欄改為上方固定（搜尋、語言、白地圖・テスト・共有）、「表示設定」可展開（收起時顯示「詳細・起伏図 60%」之類的摘要）、主體為等級＋類別＋清單、「都道府縣」「群組」可展開；開合狀態記在瀏覽器。手機抽屜同結構。
- 6：日文等級名稱改為「基本／標準／発展」，中文維持「主要／次要1／次要2」。
- 7：起伏圖不再內嵌，改為 `relief.png`、`relief_gray.png` 勾選時才下載，再轉成 data URL 放進地圖（輸出圖片時才不會被瀏覽器擋掉）。index.html 1.71 MB → 1.08 MB，首次傳輸量預估約 711 KB → 290 KB。限制：單獨存下 index.html 離線開啟時起伏圖無法載入（使用者接受）。
- 8：找不到對應語言的語音時不再用其他語言的聲音念，改顯示雙語提示（日文介面附中文、中文介面附日文）。VOICEVOX 日語音檔需使用者先安裝 VOICEVOX，待進行。

### 18. VOICEVOX 日語讀音、語音提示改單一語言（dd82bfe）
- 使用者指定角色：剣崎雌雄（VOICEVOX speaker 21）。
- `tools/voice.js`：以清單的假名讀音（不讀漢字，避免地名讀錯）呼叫本機 VOICEVOX 引擎產生語音，每個類別接成一個 MP3（每筆間隔 0.3 秒，24 kHz、40 kbps，以 lamejs 編碼；lamejs 的 npm 模組版在 Node 會報 MPEGMode 錯誤，改載入 lame.all.js），並輸出每筆的起點與長度 `voice.json`（內嵌於頁面）。
- 網頁：日文介面點地名時下載該類別的 MP3，以 Web Audio 播放對應片段；下載或解碼失敗時改用裝置語音。中文讀音仍用裝置語音。側欄底部標示「音声：VOICEVOX:剣崎雌雄」。
- 缺少語音的提示改回單一語言：日文介面缺日語語音顯示日文提示，中文介面缺中文語音顯示中文提示。

## 已知限制
- 土地分類メッシュ為昭和54年、1 km，各縣分類標準不一；平野之間的分界由本站判定，不是官方邊界。
- 手繪地形（簡易版範圍、部分點位）為學習用概略值。
- 國土數值情報河川資料的使用條件為非商用。
- PDF 輸出需要網路（從 cdnjs 載入 jsPDF）。
